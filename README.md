# Model Mismatch Trade-offs in LMMSE Estimation - MATLAB Implementation

This repository contains a MATLAB implementation of the numerical experiments presented in the paper:

> **"Model Mismatch Trade-offs in LMMSE Estimation"**  
> *Authors:* Martin Hellkvist, Ayca Ozcelikkale  
> *Published in:* IEEE  
> *Link:* [https://ieeexplore.ieee.org/document/9615976](https://ieeexplore.ieee.org/document/9615976)

## 📌 Overview

This code reproduces the numerical results from the paper, which analyzes the performance of the **Linear Minimum Mean Squared Error (LMMSE)** estimator under **model mismatch** — where the assumed model order is smaller than the true system order.

Key contributions of the paper include:
- Analytical expressions for the expected MSE under model mismatch.
- Insights into how the MSE depends on the number of samples, model orders, and signal-to-noise ratio (SNR).
- Demonstrations that increasing sample size or model complexity does not always improve performance.

## 📁 Repository Structure

- `misLMMSE.m` – Main MATLAB script that simulates the LMMSE estimation under model mismatch.
- `README.md` – This file.

## 🛠 Requirements

- MATLAB R2018b or later
- Statistics and Machine Learning Toolbox (for `mvnrnd` and `pinv`)

## 🚀 How to Run

1. Clone or download this repository.
2. Open MATLAB and navigate to the folder containing `misLMMSE.m`.
3. Run the script:
   ```matlab
   misLMMSE
   ```
4. The script will generate a semi-log plot showing the empirical MSE for different values of:
   - `p_s` (assumed model order)
   - `n` (number of samples)

## 📊 Output

The script produces a plot comparing:
- The empirical MSE for different values of `p_s` (the assumed model order).
- The MSE of the true LMMSE estimator (no model mismatch).

The plot uses a logarithmic y-axis to better visualize the MSE behavior across different regimes (e.g., when `n` is close to `p_s`).

## ⚙️ Parameters

You can modify the following parameters in the script:

- `M`: Number of Monte Carlo simulations (default: 100)
- `p`: True dimension of the unknown vector `x` (default: 30)
- `test`: Values of `p_s` to test (default: `[5,15,25,29,30]`)
- `x`: Range of sample sizes `n` to test (default: `1:50`)
- `sigma_v`: Noise standard deviation (default: 0.5)
- `sigma_hat_z`: Assumed noise standard deviation in the mismatched model (default: 0)

## 📈 Example Result

The plot generated by the script illustrates the "double descent" phenomenon and the performance degradation when the number of samples `n` is close to the assumed model order `p_s`, as discussed in the paper.

## 📚 Related Work

This implementation corresponds to the experimental setup referred to as **(S1)** in the paper:
- High SNR case
- Identity covariance for `x`
- Zero assumed noise in the mismatched model

Other scenarios (S2–S4) can be implemented by modifying the covariance and noise parameters in the code.
